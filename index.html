Meal Planner — Hospital Meal Management System

A full-featured desktop application built for hospital use, managing meal orders across multiple wards with role-based access, dietary tracking, and PDF report generation.

Login Screen — Secure user authentication with role-based access control. Supports 5 user roles: Level 3, Level 4, Maternity, Dietitian, and Admin.

Main Screen — Overview of the meal management system showing patient orders, ward summary, and quick access to all features.

Dashboard — Main overview screen showing meal order summary and quick navigation to different hospital ward levels.

Order Management — Create, view, edit, and delete patient meal orders. Supports filtering by ward, date, and dietary type.

Dietary Management — Manage multiple diet types, beverage associations, and special dietary requirements per patient.

Multi-Ward Support — Tailored meal options for Level 3, Level 4, and Maternity wards, each with their own menu configurations.

PDF Export — Generate professional PDF meal plan reports for each ward, ready for printing or sharing with kitchen staff.

Settings & Admin — Admin panel for managing users, menu items, beverages, and system configurations across all hospital levels.
